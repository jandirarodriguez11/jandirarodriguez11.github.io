# Jandira Rodríguez

Tarjeta de contacto digital estática para GitHub Pages.

El nombre, el correo y el WhatsApp están en `config.js`. El número va en formato internacional, sin `+` ni espacios. **Guardar contacto** descarga un `.vcf` con esos datos.

## Publicar

1. Sube los cambios a la rama `main`.
2. En GitHub, abre **Settings → Pages**.
3. Elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.

El sitio quedará en `https://jandirarodriguez11.github.io/`.

Las hojas de estilo, los scripts y el contacto usan rutas relativas, así que siguen funcionando si más adelante apuntas un dominio propio a esta página. Para eso, crea un archivo `CNAME` en la raíz con tu dominio y configúralo en Pages.
